# Luxury Color Palettes — Cubixso reference library

Stored palettes for reuse across the site. When applying to the dark, cobalt
premium theme, prefer the COOL jewel tones (deep blue, teal, indigo, azure) and
use saturated brights only as small accents — never fill a section with a light
cream on the dark void.
